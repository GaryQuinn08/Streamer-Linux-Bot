Comparte un diseño

Las tres opciones permiten usar, modificar y compartir el diseño, incluso para fines comerciales. Elige qué condiciones quieres aplicar.

El nombre, la descripción y los componentes se toman del archivo .slbpack. Tu perfil y esta licencia se aplican a todo el paquete. Abre el creador de paquetes para preparar tu archivo.

Al publicar se muestran de inmediato los ajustes visuales y las animaciones. Tu HTML y CSS personalizados se quedan en el archivo original. El JavaScript se descarga por separado y nunca se publica.

Al publicar, confirmas que tienes derecho a compartir este diseño con el crédito y la licencia elegidos.

Mientras se habilita Google, el editor permite Proponer diseño en GitHub con los ajustes visuales.
