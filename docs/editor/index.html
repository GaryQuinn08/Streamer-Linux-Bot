Adaptar una alerta de Streamlabs

En Streamlabs, copia el campo Plantilla de mensaje, no la URL privada del widget. El texto se adapta aquí mismo, sin conectarse a Streamlabs.

Adapta texto y etiquetas compatibles. No importa archivos .overlay, sonidos, reglas, imágenes ni JavaScript. Si conservas el widget alojado en Streamlabs, agrega su URL privada directamente en OBS como fuente de navegador.
