Adaptar una alerta de Streamlabs

En Streamlabs, copia el campo Plantilla de mensaje, no la URL privada del widget. El texto se adapta aquí mismo, sin conectarse a Streamlabs.

Adapta texto y etiquetas compatibles. No importa archivos .overlay, sonidos, reglas, imágenes ni JavaScript. Si conservas el widget alojado en Streamlabs, agrega su URL privada directamente en OBS como fuente de navegador.

02 · PRUEBAS

Vista previa

Muestra local

Arrastra el control o usa las flechas. Mayús + flecha mueve más.

La vista no se conecta a chats ni transmite.

Muestra los controles técnicos. Nada de JavaScript se ejecuta al activar la casilla.

Código de tu tarjeta

Usa etiquetas como <strong> y clases. {title} y {body} insertan tus campos. No se ejecuta JavaScript.

Estilos, transiciones y animaciones locales. Sin url() ni @import.

Prueba una función con un evento ficticio. Usa mostrar(...) para ver texto. Sin DOM, red ni datos reales.

Todavía no se ejecutó JavaScript.

El JavaScript personal no va en el HTML de OBS, en enlaces de ajustes ni en la galería.
